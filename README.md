# Мультиагентная система для разработки ПО

Проект технического задания: [TECHNICAL_SPECIFICATION.md](TECHNICAL_SPECIFICATION.md).
В нём определены требования, sandbox-изоляция, критерии приёмки и этапы реализации.

## Границы проекта

Здесь разрабатываются собственные LLM-агенты, оркестрация, инструменты, память,
валидация, изоляция выполнения, оценки качества и наблюдаемость.
Код приложения размещается в `src/`.

Kaibain — отдельный проект визуализации задач. Агентная логика в его репозиторий
не добавляется. Будущая интеграция должна использовать публичный интерфейс
Kaibain, не обращаться напрямую к его базе данных.

## Согласованное направление

- Сценарий: разработка ПО по задачам пользователя.
- Собственные агенты на базе LLM и выбранного после сравнения фреймворка.
- Координатор, разработчик и независимый валидатор; модель валидатора другого семейства.
- Jev-подобный компонент принятия решений и маршрутизации.
- OpenCode — возможный инструмент сравнения; основной агентный цикл реализуется здесь.
- MacBook Air M4, 16 ГБ RAM: управление системой и среды выполнения.
- PC: Windows 10, Ryzen 7500F, RX 7700 XT 12 ГБ VRAM, 32 ГБ RAM — сервер моделей.
- Локальные модели исследуются обязательно; бесплатные облачные API можно сравнить с ними.
